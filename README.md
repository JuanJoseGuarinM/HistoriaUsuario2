## Instrucciones de Inicio
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Inicializar base de datos con la cuenta administradora:
   ```bash
   npm run seed:admin
   ```
3. Iniciar en desarrollo:
   ```bash
   npm run dev
   ```
